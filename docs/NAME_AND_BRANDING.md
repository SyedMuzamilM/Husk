# Name & Branding — Husk

**Status:** ✅ **Decided**  
**Product name:** **Husk**  
**Date locked:** 2026-07-14  

---

## Decision

| Field | Value |
|---|---|
| **App name** | Husk |
| **Metaphor** | The outer shell you peel away — caches, leftovers, build junk. What’s left is yours. |
| **Primary tagline** | Peel the husk. |
| **Secondary** | What’s left is yours. |
| **Domain (target)** | `husk.fit` (primary) · `huskmac.com` (backup/redirect) · `husk.app` if available |
| **Bundle ID (suggested)** | `fit.husk.Husk` or `com.huskmac.Husk` |
| **Helper** | `fit.husk.Helper` |
| **MCP binary** | `husk-mcp` |
| **Xcode project** | `Husk` |

### Why Husk won

- Short, Mole-class iconicity (1 syllable)
- Clear cleanup metaphor without copying digger animals (Mole / Burrow)
- Calm, premium tone matches trash-only / zero-fear product ethics
- Domains available at research time: **`husk.fit`**, **`huskmac.com`**, **`huskhq.com`** (confirm + buy ASAP)

### Alternatives considered (not chosen)

| Name | Why not |
|---|---|
| Dross | Strong, more industrial — tabled |
| Vole | Too close to Mole (clone risk) |
| Chaff | Strong metaphor — backup |
| Sett | Needs compound domain |
| MacClear | Too generic |

Full scoring history and domain methodology remain in git history if needed; this file is now the **source of truth for the locked brand**.

## Brand attributes

| Attribute | Expression |
|---|---|
| Honest | Numbers you can verify in Finder |
| Calm | No red crisis UI |
| Sharp | Fast scans, native feel |
| Modern | MCP, local AI, SwiftUI |
| Fair | $9.99 lifetime |

### Voice

- Short sentences  
- Prefer specifics (“DerivedData 18.4 GB”) over adjectives (“huge mess”)  
- Respect the user as competent  
- Light dry humor OK: “No husk found. Nice.”

### Visual metaphor

| Use | Avoid |
|---|---|
| Shell / seed / peel / natural layers | Copying Mole’s planets |
| Disk as something you uncover | Scare “infection” graphics |
| Soft materials, one warm accent | Fake system health gauges |

Suggested accent: warm husk/amber or soft oat + one cool accent for metrics — finalize in design.
