Decisions for the next implementation

01

Session retention

Gemini’s tmp contains chats. Codex history has database references. Claude projects may include persistent memory. Deleting a directory can break resume or lose work.

Proposed default: keep sessions, link to owner controls, then build an export-first retention flow for one verified tool at a time.

02

Worktree lifecycle

A clean status can hide ignored files, nested repositories and running builds. Git owns linked registrations. Moving a working copy directly to Trash can leave broken references.

Proposed default: keep inspection. Add Git-managed removal only after activity and ignored-file checks, with a fresh review and backup path.

03

Obsolete tools and versions

Mole verifies the active executable, keeps rollback versions and checks updater locks. A version’s modified date alone is insufficient. Husk currently preserves installed versions and runtimes.

Proposed default: resolve installer ownership and the active version first. Keep at least one verified rollback version.
