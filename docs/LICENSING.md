Contributors may submit patches and necessary excerpts to the official project. They keep copyright and permit the maintainer to distribute their contributions as part of Husk under the project terms. See [contributing](../CONTRIBUTING.md).

## Why the project says source-available

Open-source licenses must permit redistribution. Husk's restriction means it should be described as source-available, not open source. Do not use an MIT badge, an OSI-approved badge, or an open-source Reddit flair for the current offering. See the [Open Source Definition](https://opensource.org/osd), especially its redistribution and derived-work requirements.

The repository previously used MIT, including commit `2f8e84a` before this change. The [original MIT notice](licenses/Husk-MIT-legacy.txt) is preserved. Anyone who received material under MIT retains those permissions, including redistribution subject to MIT's conditions. Changing the current license does not erase those rights or make that earlier code exclusive to the new license.

Publishing Git history containing MIT versions also makes those versions available with their historical license. This change is not a way to prevent people from using or redistributing the earlier MIT code. Later original changes can be offered under the new terms; third-party and prior grants must still be respected. The historical notice is not a blanket MIT grant for new changes.

## Public GitHub repositories permit on-platform forks

GitHub's terms give users viewing and forking rights for public repositories on its service. The Husk license preserves any rights separately granted under those terms. A public GitHub repository cannot promise an absolute ban on every copy or fork. See [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

The repository was private when checked on 2026-10-19. This local license change does not change its visibility or publish a release. Source-available licensing describes the permissions, not whether the public can currently access the repository.
