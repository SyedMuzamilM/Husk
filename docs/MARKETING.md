## 2. Positioning

### Positioning statement

> **For developers and power users who don’t trust subscription cleaners,**  
> **Husk** is a native macOS utility that peels away caches, leftovers, and build artifacts with full path-level transparency.  
> **Unlike CleanMyMac**, it never uses fear metrics or annual fees.  
> **Unlike Mole**, it adds long-term metrics history, port tools, and MCP for AI agents — at **$9.99** lifetime.

### Category frame

Not “antivirus.” Not “optimizer score.”  

**Husk is:** a calm disk + system toolkit — Clean · Analyze · Apps · Status · (Premium: Network, history, MCP, dev/AI purge).

## 3. Audience

### Primary: Full-stack / indie developer

- MacBook always low on disk  
- Xcode + Node + Docker + browsers  
- Hates CleanMyMac ads  
- Will pay $10 once for Xcode/LLM cleanup + ports  

**Jobs to be done**

1. Free 20–50 GB safely  
2. Uninstall apps without leftovers  
3. Kill stuck `:3000` processes  
4. See *why* the fan is loud  

### Secondary: AI-native builder

- Runs Ollama / LM Studio  
- Uses Cursor / Claude Code  
- Needs model blob cleanup + agent-readable disk status  

### Tertiary: Privacy power user

- Wants AppCleaner + DaisyDisk-class tools in one place  
- Zero account, zero tracking  

### Not for

- Users seeking antivirus theater  
- People who want “one click make Mac faster” placebo  
- Mac App Store–only installers (sandbox blocks depth)

## 5. Messaging pillars

### Pillar 1 — Peel, don’t panic

Husk never invents urgency. Safety labels. Paths visible. Trash only.

**Proof:** UI screenshots of path list + safety chips; Safety policy page.

### Pillar 2 — Built for how you actually work

Developer and AI artifacts are first-class, not an afterthought.

**Proof:** Before/after GB from DerivedData / Ollama; port table demo.

### Pillar 3 — Fair ownership

One-time price. Lifetime updates for the 1.x line. Free tier isn’t a hostage demo.

**Proof:** Feature comparison Free vs Premium; no blurred scan results.

### Pillar 4 — Local and quiet

No telemetry SDKs. Metrics stay on disk. Optional update check only.

**Proof:** Privacy page; network monitor during first run (marketing video).

## 11. FAQ (public)

**Is Husk safe?**  
We only move items to Trash. SIP-protected paths are never selectable. You preview every path.

**Do you sell my data?**  
No telemetry. Processing is local. License activation and update checks are the only network use.

**Why not on the Mac App Store?**  
Deep Library scans and privileged metrics need more access than the sandbox allows.

**What permissions?**  
Full Disk Access for thorough cleans. Guided in-app.

**Free vs Premium?**  
Free: clean standard caches, treemap, uninstall apps. Premium: developer/AI profiles, history, ports, MCP, advanced monitoring.

**Refunds?**  
14 days via our payment provider.
