# Historical design references

These exports preserve early Husk design explorations. The native SwiftUI app does not load their HTML, remote fonts, scripts, or images. The current interface is implemented under `Husk/Husk/Views`.

The owner's MIT grant covers original Husk design work, logo, and app icon. Third-party logos and external resources keep their own terms and do not imply endorsement. The HTML references Tailwind CSS, Google Fonts including Inter and JetBrains Mono, Material Symbols, and hosted image URLs. Opening these references can make network requests; the native app's local-only policy does not describe these historical web exports.

Before reusing an external asset in a new distribution, inspect its original license and preserve required notices. Do not copy these export dependencies into the app without review. See [NOTICE.md](../NOTICE.md) and [the source inventory](../docs/SOURCE_PROVENANCE.md).
